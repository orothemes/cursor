# Desdobra

Ferramenta HTML local para desdobramento de apostas de futebol (resultado final 1X2).

## Como usar

Abra o arquivo `desdobramento.html` no navegador (duplo clique ou sirva a pasta com qualquer servidor estático).

1. Adicione os jogos (casa x fora)
2. Em cada jogo, marque **1**, **X** e/ou **2** e (opcional) as odds
3. Escolha o modo:
   - **Completo 1X2** — gera todas as combinações dos resultados marcados
   - **Âncora + Triplas** — 1 fixa em todos os bilhetes + desdobro curto
4. Informe o stake do pacote — o valor é dividido igualmente entre os bilhetes
5. Copie os bilhetes ou exporte CSV
